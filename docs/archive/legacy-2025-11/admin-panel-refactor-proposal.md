# Investor AI Admin Panel 重构方案

> 参考产品：Stripe Dashboard、Vercel Dashboard、Linear、Clerk、Mixpanel、Amplitude
>
> 文档版本：v1.0
>
> 最后更新：2024-12

---

## 一、执行摘要

本方案参考业界顶级 SaaS 产品的 Admin 设计模式，对 Investor AI 管理后台进行全面重构。核心目标是打造一个**数据驱动、权限清晰、操作高效**的企业级管理系统。

### 参考产品分析

| 产品 | 核心亮点 | 借鉴点 |
|------|----------|--------|
| **Stripe** | 简洁导航、交易管理、客户门户 | 侧边栏最近访问、一键操作、自助服务门户 |
| **Vercel** | 团队/项目层级、Spend Management、角色权限 | 作用域选择器、预算管控、细粒度 RBAC |
| **Linear** | Workspace/Team 结构、Admin 独立区域 | 管理员专属设置区、团队层级管理 |
| **Clerk** | 用户管理、预构建组件、审计日志 | 用户表格、批量操作、角色配置、审计追踪 |
| **Mixpanel/Amplitude** | 数据可视化、用户行为分析、漏斗 | 指标卡片、趋势图表、留存分析、用户分群 |

### 2.2 权限层级（参考 Vercel + Clerk）

| 角色 | 等级 | 权限范围 | 危险等级 |
|------|------|----------|----------|
| **super_admin** | 5 | 全部权限 + 管理其他管理员 + 系统配置 | 🔴 最高 |
| **admin** | 4 | 用户管理 + 内容管理 + 数据查看 | 🟠 高 |
| **operator** | 3 | 用户支持 + 积分操作 + 只读数据 | 🟡 中 |
| **viewer** | 2 | 只读访问（报表、用户列表） | 🟢 低 |

**关键设计原则：**
- 角色变更与普通用户编辑分离（已完成）
- 授予 admin 及以上角色需二次确认（已完成）
- 所有权限变更记录到审计日志

#### 3.1.2 功能清单

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **统计卡片** | 总用户/新增/活跃/付费/流失风险，支持点击下钻 | P0 |
| **增长趋势图** | 30天用户增长曲线，新增vs流失 | P1 |
| **用户构成图** | 按套餐/角色/活跃度分布饼图 | P1 |
| **高级筛选器** | 多维度筛选：时间/套餐/标签/积分/活跃度 | P0 |
| **用户标签系统** | 自动标签（流失风险/高价值）+ 手动标签 | P1 |
| **活跃度评分** | 基于登录频率/报告生成/最后活跃时间计算 | P1 |
| **批量操作** | 发送通知/修改套餐/添加标签/导出/删除 | P0 |
| **用户详情侧边抽屉** | 点击行展开详情，不跳转页面（参考 Stripe） | P1 |
| **数据导出** | CSV/Excel 导出，支持筛选后导出 | P2 |

#### 3.1.3 用户详情页 `/admin/users/[id]`

保持现有 Tab 结构，增强以下内容：

- **账户 Tab**: 移除角色编辑（已完成），增加用户来源、设备信息
- **积分 Tab**: 增加积分流水图表、消耗趋势
- **报告 Tab**: 增加报告分类统计、常查股票
- **订阅 Tab**: 增加订阅历史时间线、续费预测
- **行为 Tab**（新增）: 登录记录、操作轨迹、漏斗分析

**关键指标说明（参考业界标准）：**

| 指标 | 计算方式 | 健康基准 |
|------|----------|----------|
| MRR | 所有活跃订阅月费总和 | 持续增长 |
| ARR | MRR × 12 | - |
| Net Revenue Retention | (期末MRR - 新客MRR) / 期初MRR | > 100% |
| Churn Rate | 流失客户 / 期初客户 | < 5% |
| ARPU | 总收入 / 活跃用户数 | 持续提升 |
| LTV:CAC | 客户终身价值 / 获客成本 | > 3:1 |
| Rule of 40 | 增长率 + 利润率 | > 40% |

#### 3.4.1 用户分析 `/admin/analytics/users`

```

1. 用户增长曲线（新增/累计/净增长）
```
