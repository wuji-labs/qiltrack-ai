**Purpose:** Replace old glass-effect navigation with minimalist sticky header

**Features:**

**Key Implementation Details:**

```tsx
<header className="sticky top-0 z-50 w-full border-b border-gray-200 bg-white/80 backdrop-blur-sm">
  <Container>
    <nav className="flex h-16 items-center justify-between">
      {/* Logo */}
      <Link href="/" className="flex items-center gap-2">
        <Search className="w-5 h-5 text-gray-900" />
        <span className="font-semibold text-gray-900">Qiltrack AI</span>
      </Link>

      {/* Desktop Navigation */}
      <div className="hidden md:flex items-center gap-6">
        {navItems.map((item) => (
          <a href={item.href} onClick={(e) => onNavClick(item.href, e)}>
            {item.label}
          </a>
        ))}
      </div>

      {/* User Menu / Auth Buttons */}
      {isAuthenticated ? (
        <DropdownMenu>
          {/* User avatar, credits, plan info */}
        </DropdownMenu>
      ) : (
        <Button asChild>
          <Link href="/login">Sign In</Link>
```

### 2.3 Model Selector Component (`app/sections/ModelSelectorNew.tsx`)

**Purpose:** Redesigned research mode selector with card-based UI

**Features:**
- 4 research modes: Baseline, Buffett, Musk, Muddy Waters
- Icon integration (Target, Castle, Rocket, Shield from lucide-react)
- Badge system showing mode type and credit cost
- Click-to-select interaction with visual feedback
- Hover effects (shadow, translate-y animation)
- Selected state indicator (ring-2 ring-gray-900)
- Current mode summary below cards

**Key Implementation Details:**

```tsx
const iconMap = {
  baseline: Target,
  buffett: Castle,
  musk: Rocket,
  muddy: Shield,
};

<Section id="models" spacing="default" className="bg-gray-50">
  <Container>
    <Grid cols={{ default: 1, sm: 2, lg: 4 }} gap={6}>
      {options.map((option) => {
        const Icon = iconMap[option.id];
        const isSelected = option.id === selected;

        return (
          <Card
            onClick={() => onSelect(option.id)}
            className={cn(
              "group cursor-pointer transition-all duration-200",
              "hover:shadow-lg hover:-translate-y-1",
              isSelected
                ? "ring-2 ring-gray-900 shadow-md"
                : "hover:ring-1 hover:ring-gray-300"
            )}
          >
            <CardContent className="pt-6">
              <Icon className="w-8 h-8" />
              <h3>{option.title}</h3>
              <Badge variant="secondary">{option.badge}</Badge>
              <Badge variant="outline">{option.credits} credits</Badge>
              <p>{option.description}</p>
              {isSelected && <p className="text-xs">✓ Selected</p>}
            </CardContent>
          </Card>
        );
      })}
    </Grid>
  </Container>
</Section>
```
