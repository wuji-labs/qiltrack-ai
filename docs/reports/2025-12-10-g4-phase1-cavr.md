**cn 函数**：
```typescript
import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

## 附录 C：关键决策记录

### C.1 为何选择 RGB 格式的 CSS 变量？

**决策**：自定义 CSS 变量使用 RGB 格式（如 `--bg-base: 255 255 255`）

**理由**：
- 便于动态调整透明度：`rgb(var(--bg-base) / 0.5)`
- Tailwind v4 推荐格式
- 避免与 shadcn 的 HSL 格式冲突

### C.2 为何同时保留两套 CSS 变量？

**决策**：保留自定义变量（`--bg-base`, `--fg-primary` 等）+ shadcn 变量（`--background`, `--foreground` 等）

**理由**：
- 自定义变量更直观（`--bg-base` 比 `--background` 语义更清晰）
- shadcn 组件依赖其变量命名
- 未来可以逐步统一，Phase 1 先确保兼容性

### C.3 为何选择浅色为默认主题？

**决策**：`defaultTheme="light"` 而非 `"dark"`

**理由**：
- 金融/专业类产品浅色主题更权威
- 数据密集页面浅色背景可读性更好
- Architecture Snapshot 明确要求

## Phase 1.5: 构建失败修复 (2025-12-10)

### 背景

Phase 1 初次提交后，Codex Code Review 发现 2 个 P0 阻塞问题导致 `npm run build` 失败：
1. ❌ **P0-001**: Tailwind v4 配置冲突
2. ❌ **P0-002**: Google Fonts 网络依赖

### 修复动作

#### 1. 诊断构建错误

**错误 1**: "It looks like you're trying to use `tailwindcss` directly as a PostCSS plugin"
- **原因**: 使用了 v3 的 `tailwindcss: {}` 而非 v4 的 `"@tailwindcss/postcss": {}`
- **修复**: 更新 `postcss.config.mjs` 使用 `"@tailwindcss/postcss": {}`

**错误 2**: "Missing opening ("
- **原因 1**: `components.css` 中使用 `@apply btn-gradient-legacy` 尝试应用自定义类（Tailwind v4 不支持）
- **原因 2**: `utilities.css:64` 缺少 `var()` 函数：`color: rgb(--fg-secondary));` → `color: rgb(var(--fg-secondary));`
- **修复**:
  - 移除 `@apply` 别名，改用 CSS 多选择器语法 `.btn-gradient, .btn-gradient-legacy { ... }`
  - 修复 CSS 语法错误

**错误 3**: "Cannot apply unknown utility class `border-border`"
- **原因**: `@layer base` 中使用 `@apply border-border` 等 shadcn 自定义工具类
- **修复**: 将 `@apply` 指令替换为普通 CSS：`border-color: hsl(var(--border));`

#### 2. 代码修改清单

| 文件 | 修改内容 |
| ---- | -------- |
| `postcss.config.mjs` | `tailwindcss: {}` → `"@tailwindcss/postcss": {}` |
| `app/globals.css` | `@tailwind base/components/utilities` → `@import "tailwindcss"`<br>`@layer base { @apply ... }` → 普通 CSS 规则 |
| `app/styles/utilities.css:64` | `rgb(--fg-secondary))` → `rgb(var(--fg-secondary))` |

### 经验总结

1. **Tailwind v4 限制**: `@apply` 只能用于 Tailwind 内置工具类，不能用于自定义类
2. **CSS-first 冲突**: `@import "tailwindcss"` 与 `@layer` 指令可能不兼容，建议使用普通 CSS
3. **构建验证**: 每次结构性改动后必须运行 `npm run build` 验证，不能只依赖 dev 模式
4. **系统字体优先**: 避免网络字体依赖可提升首屏加载速度并满足合规要求
