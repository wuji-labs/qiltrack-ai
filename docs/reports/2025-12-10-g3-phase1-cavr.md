## Actions (已执行操作)

### 1. 创建 Design Tokens 系统
**文件**: `app/styles/tokens.css`

#### 定义内容
- **配色系统**:
  - 浅色模式：白色背景 (#ffffff) + 蓝色主色 (#0070f3)
  - 文本层级：primary/secondary/tertiary/placeholder
  - 语义色：success/warning/error/info
  - 边框与阴影：4 级阴影系统

- **尺寸系统**:
  - 圆角：xs(4px) → xl(16px) + full(9999px)
  - 间距：基于 8px 基准，1-24 级
  - 过渡时间：fast(150ms) / base(200ms) / slow(300ms)

- **深色模式**: 预留支持（使用 `data-theme="dark"` 属性）

#### 代码量
- 新增 137 行 CSS 变量定义
- 完整覆盖 Phase 2-7 所需 tokens

### 2. 重构 Global Styles
**文件**: `app/globals.css`

#### 主要改动

**✅ 引入新系统**:
```css
@import "tailwindcss";
@import "./styles/tokens.css";
```

**✅ 移除旧变量**:
- 删除 `:root` 中的 25 行旧变量定义（--bg-base, --stroke-soft 等）
- 删除旧的 `@theme inline` 重复定义

**✅ 移除华丽动画** (性能优化):
- ❌ `glow-pulse` (Hero 按钮光晕)
- ❌ `gradient-shift` (渐变移动)
- ❌ `sheen-move` (光泽扫过)
- ❌ `spark-move` (火花移动)
- ❌ `stack-bounce` (弹跳动画)
- ❌ `marquee-float` / `marquee-shell-drift` (漂浮动画)

**✅ 保留核心动画**:
- ✅ `fade-in-up` (淡入上滑 - 200ms)
- ✅ `spinner-rotate` (加载旋转 - 800ms)
- ✅ `slideDown` (滑下 - 300ms)

**✅ 向后兼容策略**:
```css
/**
 * @deprecated 这些样式类将在后续版本中移除
 * .glass-card -> 使用 <Card /> 组件
 * .btn-gradient -> 使用 <Button variant="primary" />
 */
.glass-card { /* 保持可用但简化 */ }
.btn-gradient { /* 更新为新配色 */ }
```

**✅ 禁用网格背景**:
```css
.hero-mesh,
.feature-mesh,
.generator-mesh {
  opacity: 0; /* 暂时禁用 */
}
```

**✅ 简化 Progress 组件**:
- 移除复杂的多层光晕效果（`progress-fill-glow`, `progress-chip-spark` 等）
- 使用新的配色系统
- 保持核心功能

#### 代码量变化
- 删除：443 行（旧变量 + 复杂动画 + 冗余样式）
- 新增：307 行（简化样式 + 兼容性注释）
- 净减少：136 行 (23% 体积优化)

## Risks (风险与限制)

### 🟡 中等风险

1. **视觉变化可能较大**
   **原因**: 网格背景被禁用，按钮配色从绿色改为蓝色
   **缓解**:
   - 旧样式类保持向后兼容
   - Phase 2 将逐步迁移组件
   - 可快速回滚（仅 1 个 commit）

2. **深色模式未实现**
   **原因**: Phase 1 仅实现浅色模式
   **缓解**:
   - Tokens 预留深色变量
   - 切换逻辑留待 Phase 2-3

3. **Lint 错误未修复**
   **原因**: 项目原有 11 errors 未在此 Phase 处理
   **缓解**:
   - 这些错误与 Phase 1 无关
   - 需独立 PR 修复（建议建 `cleanup/lint-warnings` 分支）

### 🟢 低风险

4. **CSS 变量引用可能失效**
   **原因**: 部分组件可能引用已删除的旧变量
   **缓解**:
   - 在 Phase 2 实施前会发现并修复
   - 使用浏览器 DevTools 快速定位
