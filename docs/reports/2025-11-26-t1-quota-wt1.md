## 功能实现细节

### 后端 - 配额管理

#### `/api/report/credits` (app/api/report/credits/route.ts)

- **功能**: 返回已登录用户的实时剩余额度
- **鉴权**: 依赖 NextAuth session，未登录返回 401
- **数据源**: Supabase `v_user_quota` 视图（RLS 保护）
- **响应格式**:
  ```json
  {
    "userId": "user-id",
    "credits": {
      "remaining_credits": 1
    }
  }
  ```

#### `lib/services/quota.ts` 配额服务

- **getRemainingCredits(userId)**: 获取用户剩余额度
- **consumeReportCredit(userId, testMode)**: 扣减 1 个额度（原子操作）
  - 生产模式: 调用 Supabase RPC `fn_consume_report_credit`
  - 测试模式: 返回 999 余额（不实际扣减）
- **writeReportAudit()**: 记录报告生成事件到 `report_credit_events`

### 前端 - UX 集成

#### HeroSection (app/sections/HeroSection.tsx)

- **属性**: `isAuthenticated`, `planLabel` 用于显示认证状态
- **CTA 逻辑**: 未登录 → 显示注册提示；已登录 → 生成报告

#### ReportGeneratorSection

- **流程**:
  1. 用户点击生成 → 检查认证状态
  2. 未登录 → 打开登录窗
  3. 已登录 → 发送 `/api/report`
  4. 成功生成 → 刷新 session（同步配额扣减）
  5. 额度耗尽 → 显示 429 提示文案

#### 支付 CTA 安全化

- **未接通状态**: Stripe 未接通时，按钮改为 `联系开通`
- **Fallback**: 弹出登录窗或跳转到定价页面
