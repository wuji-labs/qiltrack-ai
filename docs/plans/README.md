# Investor AI 报告风格提示词系统

本目录包含 Investor AI 四种报告风格的完整提示词文档。

## 风格概览

| 风格 | 文件 | 定位 | 适用场景 |
|------|------|------|----------|
| **Baseline** | `baseline.md` | 中立客观研究员 | 标准分析，无特定倾向 |
| **Buffett** | `buffett.md` | 价值投资者 | 长期持有、护城河分析 |
| **Musk** | `musk.md` | 科技信仰者 | 创新企业、高增长潜力 |
| **Muddy** | `muddy.md` | 做空分析师 | 风险排查、财务审计 |

## 文档结构

每个提示词文档包含以下标准章节：

```
1. 角色定义        - AI 扮演的专业角色
2. 核心投资哲学    - 该风格的投资理念
3. 分析框架
   3.1 关键评估维度（带权重）
   3.2 章节定制指引（针对报告 0-8 章节）
   3.3 语气与措辞（推荐/禁用表达）
4. 风险提示侧重    - 该风格的风险关注点
5. 禁止事项        - 必须避免的内容
```

## 使用方式

### 当前（文档参考）

提示词文档作为参考，手动更新 `lib/core/reports/generator.ts` 中的 `TONE_DIRECTIVES`。

### 未来（自动加载）

可通过 `PromptLoader` 服务自动读取文档内容，实现提示词的热更新。

## 版本控制

每个文档的 YAML 头部包含版本信息：

```yaml
---
tone: buffett
version: 1.0.0
---
```

修改提示词时请更新版本号。

## 核心原则

1. **章节结构不变** - 所有风格必须输出固定的 0-8 章节
2. **免责声明不变** - 第 8 章必须使用固定模板
3. **语言指令优先** - 语言设置优先于风格设置
4. **理性克制** - 所有风格都禁止"确保赚钱"等表述
