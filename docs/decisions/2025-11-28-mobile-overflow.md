# 移动端横向遮挡修复（2025-11-28）

## 背景
- **当前问题**：窄屏（≈360–430px）主页除导航栏外出现右侧内容被裁切/水平溢出，发报告、概览/定价等区块在移动端无法完整展示，疑似由装饰性光晕的 `overflow-visible` 与容器缺少 `max-w`/溢出约束叠加导致。
- **影响范围**：`app/page.tsx` 主体栅格与容器、`ReportGeneratorSection` 背景层、底部区块的横向尺寸与可滚动性；导航栏逻辑与交互保持正常。

## 设计目标
1. **核心目标**：移除 ≤640px 视口的横向滚动与遮挡，保证主要区块贴合视口宽度。
2. **体验要求**：桌面端视觉与阴影/渐变不变；CTA、输入、下拉在移动端可触达、不中断。
3. **范围界定**：不新增文案、不改业务流程，仅调整容器溢出、内边距与 `max-w` 约束。

## 技术约束
- 技术栈：Next.js App Router + TypeScript + Tailwind v4（`@theme inline` 变量）；沿用现有颜色/阴影 token。
- 不新增依赖，不改 API/数据流。优先通过 `overflow-x-hidden`（全局/局部）、`max-w-full`、小屏 padding 调整解决溢出；保留动画与发光背景，但限制其可视范围。
- 受限环境：按需运行 lint/test，若无法执行需在终端标注。

## 文案 key
- 无新增，复用现有 i18n 文案。

## 测试要求
- **手动**：DevTools 模拟 360px/414px/768px，确认主页无横向滚动；发报告表单、定价卡片、FAQ 内容在窄屏未被裁切，搜索下拉与按钮可点击。
- **锚点**：导航锚点（`#generator/#overview/#pricing/#faq`）平滑滚动且停留位置正确。
- **回归**：如环境允许运行 `npm run lint`、`npm test`；否则在总结中说明未执行原因。
