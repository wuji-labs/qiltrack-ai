# 导航栏折叠态对齐调整
- **问题背景**：导航栏当前在 `lg<=宽度<xl` 时（桌面中号视口）隐藏了导航菜单，但语言切换与登录按钮被 `justify-between` 推到中间，汉堡按钮单独靠右，导致右侧分散，不符合“右侧集中排列、汉堡在语言左侧”的期望。
- **设计目标**：1) `xl` 及以上形态保持不变（完整菜单 + 右侧账户/语言/CTA）；2) `lg`-`xl` 区间仅调整排列：左侧品牌，右侧为“汉堡按钮 + 语言/登录/账户”同组对齐，汉堡位于语言左侧，中间不留悬空元素；3) `lg` 以下形态保持“品牌 + 汉堡”不变；4) 保持现有间距、毛玻璃与阴影效果，避免引入闪烁或位移抖动。
- **技术约束**：Next.js App Router + TypeScript + Tailwind v4，沿用默认断点（`lg=1024px`、`xl=1280px`）。导航实现位于 `app/sections/HeroSection.tsx`，当前结构为“品牌 | hidden xl 导航 | hidden lg 桌面按钮 | xl:hidden 汉堡”并由 `justify-between` 布局。
- **文案 key**：复用既有 i18n 文案；不新增文案、不改动导航项内容。
- **测试要求**：手动在 1440px（形态1）与 1200px（形态2）检查排布：品牌在左，形态2时右侧顺序为“汉堡 -> 语言/登录/账户”，无居中元素，点击汉堡可正常开合抽屉；在 1023px 及以下确认仅品牌 + 汉堡，抽屉内容与现有一致。若时间允许再跑 `npm run lint`。
- **实施要点（供 Claude）**：
  1) 调整导航容器布局，去掉强制 `justify-between`，在品牌后保留 `hidden xl:flex flex-1 justify-center` 的菜单；右侧新建 `ml-auto flex items-center gap-*` 容器，内部顺序为汉堡（`xl:hidden`）在前、桌面语言/账户/CTA（`hidden lg:flex`）在后。
  2) 保留现有尺寸/圆角/阴影/背景样式与最小高度设置，避免影响其他断点。
  3) 抽屉触发与 ref 逻辑保持不变，仅调整 DOM 顺序与容器对齐。
